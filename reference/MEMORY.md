## How to read and write this file

- **Every claim carries a source pointer** in square brackets: the file in `reference/evidence/` and the section or page it came from, e.g. `[evidence/CV_2026.md, Experience]`. A claim with no pointer is a claim with no evidence. Mark it `[needs source]` and do not use it in a resume.
- **Verbs match what was done.** Use the verb the source supports. If the source says you benchmarked, tuned or adapted a tool, write that. Do not upgrade it to "developed" or "built".
- **Keep every qualifier.** "On the pilot cohort", "up to", "in a test environment" stay in the sentence.
- **One bullet is one line.** No hard line breaks inside a bullet or paragraph.
- **Numbers need a source and a scope.** Say what was measured, on what, and by whom.
